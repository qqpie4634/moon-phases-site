# 八大月相互動教室

繁體中文靜態教學網站，包含太陽、地球、可拖曳月球、月齡滑桿、八大月相快捷鍵與自動播放。以臺灣常見北半球視角示意。

## 使用
直接開啟 index.html 即可，無需安裝套件、建置或 API 金鑰。

## 專案結構與擴充
- index.html：頁面與天體 SVG。
- assets/styles.css：版面、色彩與行動裝置樣式。
- assets/phases.js：八大月相名稱、農曆概略對照、教學說明與月齡。
- assets/app.js：月相繪圖、拖曳、滑桿及播放控制。

可新增測驗或課程區塊，並以獨立腳本接入；編輯教學內容時可優先修改 phases.js。

## GitHub Pages
將本目錄內容上傳至公開儲存庫根目錄。在 Settings → Pages 選擇 Deploy from a branch、main 與 /(root)，儲存後等待部署完成。所有資源使用相對路徑，支援專案子路徑部署。

## 教學限制
月齡週期採約 29.53 天；農曆日期僅為概略對照，並非即時天文曆。天體大小、距離與軌道未按比例。

## 來源與整理
來源為使用者已下載的「八大月相互動教學_太陽地球月亮_可拖動版.html」。拆分樣式、資料與互動程式，並修正軌道示意月球亮面方向，使其朝向左側太陽。
